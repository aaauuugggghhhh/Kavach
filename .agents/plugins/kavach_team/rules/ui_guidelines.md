# Kavach.ai UI Consistency Guidelines

This rule is activated when modifying UI components in `kavach_ai/frontend/`.

1. **Theming**: Enforce a unified dark mode / glassmorphism aesthetic.
2. **Typography**: Use modern fonts like `Inter` or `Outfit`. Ensure readability with proper hierarchy.
3. **Component Reusability**: Avoid inline styles and ad-hoc CSS. Use predefined design tokens (e.g., from `kavach_ai/frontend/src/index.css`).
4. **Responsiveness**: All views must use flexbox/grid to scale gracefully across different viewport sizes.
5. **Animations**: Use subtle micro-animations for interactive elements (hover states, loaders) to maintain a premium feel.
